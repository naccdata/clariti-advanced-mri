## Pipeline Description
The default pipeline is the following: 
1. Combine real and imaginary data, if needed
2. Frequency maps are generated by non-linearly fitting all the echoes from the gradient-echo sequence in the complex 
plane. (can support bipolar readout data)
3. Unwrap phase wraps using ROMEO
4. Background field removal using Projection onto Dipole Fields (PDF)
5. Additional background field removal while maintaining signal at the edges of the mask using mSMV
6. Dipole inversion with reference value is performed with MEDI+0. QSM maps have a reference value set to the QSM value 
of the CSF. Note that the background voxels have a value of the reference value. 

Various components of the pipeline can be modified with a config file, including unwrap method, background field 
removal method, application of mSMV method, and convergence parameters.

## Input Data

The pipeline operates on a zip file containing the DICOM data of the gradient echo sequence used for QSM reconstruction.
 
These are the requirements for the zip file and the DICOM data contained within it:
- The zip file must contain no other MRI sequences
- The DICOM files must be compatible with dcm2niix 
- The gradient echo sequence must have at least 2 echoes
- At a minimum, the gradient echo sequence must contain one of the two combinations:
  - real and imaginary data
  - magnitude and phase data

## Output Files

### Main Files

- QSM.nii.gz = magnetic susceptibility map in ppm units
- QSM_mask.nii.gz = mask for QSM map

Note that the QSM map has a reference value set to the QSM value of the CSF, so the background voxels have a value of 
the reference value. Therefore, it is important to use the QSM mask to exclude background voxels when visualizing or 
analyzing the QSM map.

### Intermediate Files

Not all intermediate files are generated for every run, as some are dependent on config parameters.

- iMag.nii.gz = magnitude image calculated as the root mean squared of magnitude images across echoes
- iFreq.nii.gz = unwrapped field map
- iFreq_raw.nii.gz = wrapped field map
- RDF.nii.gz = local field map
- RDF_msmv.nii.gz = local field map after mSMV processing
- R2s.nii.gz = R2s map with MEDI toolbox method (ARLO fitting)
- Mask_CSF.nii.gz = CSF mask derived from R2s processing within MEDI toolbox
- meta_data.json = metadata from input nifti files
- pipeline_meta.txt = metadata about the pipeline such as version and processing parameters
- processing.log = log of processing steps and any warnings or errors
- raw_magnitude.nii.gz = magnitude images from all echoes of the gradient echo sequence
- raw_phase.nii.gz = phase images from all echoes of the gradient echo sequence
- temp_RDFv.mat = MATLAB file containing the variables needed to run MEDI
- temp_hd-bet_input.nii.gz = input image for hd-bet brain extraction
- temp_hd-bet_output_pre.nii.gz = output image from hd-bet brain extraction before postprocessing
- temp_hd-bet_output_pre_mask.nii.gz = brain mask from hd-bet brain extraction before postprocessing
- temp_iFreq_0.nii.gz = phase offsets from field calculation (odd or all, depending on readout)
- temp_iFreq_0e.nii.gz = phase offsets from field calculation (even echoes, only for bipolar readout)
- temp_iFreq_rel_res.nii.gz = relative residuals from field calculation
- temp_magnitude_prior_to_fit.nii.gz = magnitude after preprocessing steps but before field calculation
- temp_phase_prior_to_fit.nii.gz = phase after preprocessing steps but before field calculation
- temp_reference_3d.nii.gz = 3D reference image for hd-bet

## Troubleshooting QSM results

Enable debug_mode in the config file to generate additional temporary files that can be used for troubleshooting.

- If you are seeing large streaking artifacts in your QSM maps, this is likely due to poor phase unwrapping.
  - Inspect the unwrapped field map for any open-ended fring lines, which can cause issues for ROMEO. If you see 
    open-ended fringe lines in the unwrapped field map, try switching the phase unwrapping method to 'laplacian' in 
    the config file. The laplacian method is more robust to open-ended fringe lines.

- Data with bipolar readouts (aka no flyback gradients) have echo-dependent linear phase gradients that can cause 
  issues with phase unwrapping and QSM reconstruction. It is recommended to set the bipolar_complex_fit parameter to 1 
  in the config file to perform complex fitting accounting for the discrepancies in the phase offset for odd and even 
  echoes.
